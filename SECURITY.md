# Security Policy

This repository is a docs-only guide. It ships no executable code, packages, or services to run.

- Do not run commands from this guide against apps you do not own or lack explicit permission to test.
- If you find a malicious, compromised, or otherwise unsafe tool link in the guide, please report it via a GitHub issue so it can be reviewed and removed.
- Please do not include secrets, credentials, or personal data in issues or pull requests.

This guide is maintained on a best-effort basis and carries no security guarantees about third-party tools or techniques described here.
