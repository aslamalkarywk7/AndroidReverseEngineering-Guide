# Support

## Where to ask for help

- **Questions about the guide content:** open a GitHub issue with the page/section name and what is unclear or outdated.
- **Ideas and general discussion:** use GitHub Discussions if enabled for this repository; otherwise open an issue labeled as a question.
- **Tool-specific problems (APKTool, JADX, Frida, etc.):** please check the tool's official documentation and issue tracker first, then open a guide issue only if the guide itself needs a correction.

When asking, include the guide section, the tool name and version, and your host OS where relevant.
